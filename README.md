# Ankith Mahindrakar (@whoisanki) - 3D Animated Portfolio

A 3D interactive, dark-themed developer portfolio website engineered with **React**, **Three.js / React Three Fiber**, **Framer Motion**, and **Tailwind CSS**.

Inspired by [whoisanki.github.io](https://whoisanki.github.io/), upgraded into a futuristic WebGL experience.

---

## ✨ Features

- **Interactive 3D WebGL Hero**: Custom morphing metallic core, orbiting rings, starfield, and dynamic point lighting.
- **3D Numismatics Coin Vault**: An interactive 3D coin viewer celebrating Ankit's passion for collecting coins across 26+ countries since age 12. Includes 360° rotation, coin flipping with metallic audio effects & confetti, and material toggles (24K Gold, Cyber Obsidian, Platinum Silver, Ancient Bronze).
- **Framer Motion Scroll Animations**: Parallax reveals, smooth scroll anchors, progress tracker, and 3D card perspective tilt.
- **Dark Hologram Theme**: Sleek obsidian background (`#05070f`), cyan/gold/purple neon glows, cyber grid overlays, and custom glowing cursor.
- **Web Audio FX Synthesizer**: Procedural sci-fi sound effects on click, hover, coin flip, and warp (with mute toggle in navbar).
- **Featured Projects & Modals**: Interactive showcase with filter tabs, repository links, and live demos.
- **"Hot Wings & Code" Contact Hub**: One-click email copy to `ankit.m8055@gmail.com`, mailto client launcher, and direct social channel matrix (LinkedIn, GitHub, Instagram, Facebook).

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS v4, Glassmorphism
- **Icons**: Lucide React + Custom SVG Brand Icons
- **Audio**: Web Audio API Procedural Synthesizer
- **Celebration FX**: Canvas Confetti
